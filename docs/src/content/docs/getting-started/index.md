title: Getting Started With Metakip
description: Create your first Metakip page, import existing markdown, organize pages, and share knowledge with other people.
---

Metakip gives you pages for information you want to keep, connect, and share. This guide takes you from an empty account to a small, useful set of pages.

You can write pages in the browser, group them in folders, connect related pages, and share them with other people. If you already have notes, import them instead of starting over.

If you use an AI assistant, Metakip also gives it a way to work with the same pages through the CLI. You can leave that setup until you need it.

## Before You Begin

You need a Metakip account and a browser. If you are bringing existing notes, keep a copy of the original files until you have checked the import.

## Choose Your Starting Point

- [Create A Page In Metakip](/getting-started/create-your-first-page/) walks you through your first page.
- [Markdown Support](/getting-started/markdown-support/) lists the markdown syntax Metakip supports today.
- [Bring Your Notes to Metakip](/getting-started/bring-your-notes/) helps you import an existing markdown file, folder, or Obsidian vault.
- [Organize Pages and Folders](/getting-started/organize-pages-and-folders/) shows you how to keep related information together.
- [Share a Page](/getting-started/share-a-page/) explains how to let someone else view or edit a page.
## The Basic Workflow

1. Create or import a page.
2. Give it a title that describes what it contains.
3. Add the information you want to keep.
4. Put related pages in a folder when you need more structure.
5. Link pages when one page refers to another.
6. Share a page when someone else needs to read or edit it.

Start with one useful page. You can change the structure later.

## When You Are Ready For Automation

Use [MCP](/agents/mcp/) when an AI assistant can connect to a remote MCP
service. Use the [Metakip CLI](/agents/metakip-cli/) for terminal workflows,
or the [API Reference](/api-reference/endpoints/) when you are building an
integration or script.
